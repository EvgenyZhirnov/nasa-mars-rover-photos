Анимация марсохода Rover Animation

Это приложение получает последние фотографии с миссии марсохода NASA и создаёт из них ежедневные анимации. Новые изображения загружаются 25 раз в час, а новая анимация создаётся каждый день в 16:00. This app fetches the latest photos from NASA Mars rover missions and compiles them into daily animations. New images are downloaded 25 times per hour, and a new animation is generated every day at 16:00.

О проекте About the Project

Все фотографии All Photos

Это приложение выполняет следующие задачи: This application performs the following tasks:

  • Получает фотографии марсохода через API NASA каждые 2,4 минуты (25 раз в час) Fetches Mars rover photos via NASA API every 2.4 minutes (25 times per hour)
  • Сохраняет новые изображения в каталог данных с уникальными именами файлов Saves new images to the data directory with unique filenames
  • Создаёт ежедневную анимацию в 16:00 из всех собранных за день изображений Generates a daily animation at 16:00 from all images collected that day
  • Предоставляет веб-интерфейс для скачивания и просмотра последней анимации Provides a web interface for downloading and viewing the latest animation
  • Автоматически отправляет анимацию через Telegram-бота в 16:05 Automatically sends the animation via Telegram bot at 16:05
  • Показывает астрономическое фото дня от NASA (APOD) и снимки Земли (EPIC) Displays NASA Astronomy Picture of the Day (APOD) and Earth imagery (EPIC)
