О проекте

Все фотографии

Это приложение выполняет следующие задачи:

  • Получает фотографии марсохода через API NASA каждые 2,4 минуты (25 раз в час)
  • Сохраняет новые изображения в каталог данных с уникальными именами файлов
  • Создает ежедневную анимацию в 16:00 из всех собранных за день изображений
  • Предоставляет веб-интерфейс для скачивания и просмотра последней анимации
  • Автоматически отправляет анимацию через Telegram-бота в 16:05
  • Показывает астрономическое фото дня от NASA (APOD)
